# Reasoning battery

A self-checking test of whether one language model is stronger than another at
exact, tool-free reasoning. The generator builds each problem from an answer it
already holds, so problems can be harder than the model that wrote them can solve.
A deterministic script grades every answer. No language model judges.

Work in progress: the first calibration is running. Full instructions follow when
it is complete.

- [PROTOCOL.md](PROTOCOL.md) — the full procedure and decision rules.
- [runs/](runs/) — published calibrations and results.
